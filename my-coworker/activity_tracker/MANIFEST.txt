## Database Schema (auto-created)

### activities table
- id (INTEGER PRIMARY KEY)
- timestamp (DATETIME)
- app_name (TEXT)
- window_title (TEXT)
- category (TEXT)
- keyboard_active (BOOLEAN)
- duration_seconds (INTEGER)

### sessions table
- id (INTEGER PRIMARY KEY)
- start_time (DATETIME)
- end_time (DATETIME)
- app_name (TEXT)
- category (TEXT)
- duration_seconds (INTEGER)
- keyboard_activity_percentage (REAL)

### daily_summary table
- id (INTEGER PRIMARY KEY)
- date (DATE)
- coding_seconds (INTEGER)
- music_seconds (INTEGER)
- other_seconds (INTEGER)
- total_active_seconds (INTEGER)

### Indexes
- idx_timestamp (on activities)
- idx_category (on activities)
- idx_date (on daily_summary)
